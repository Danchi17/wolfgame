# 多能力一夜人狼ゲーム

多能力一夜人狼はオンラインで遊ぶことができるワンナイト人狼ゲームです。

## 機能

- リアルタイムなゲームプレイ
- 12種類のユニークな役職
- 役職に応じた特殊能力
- 持ち点システムによる長期的な遊び
- 完全なFirebaseサポート

## 役職一覧

### 市民陣営

- **占い師**（コスト3）：他プレイヤー1人または場札2枚の役職確認
- **占星術師**（コスト2）：場札含む6枚の役職中、人狼陣営の数を知る
- **占い師の弟子**（コスト2）：他プレイヤー1人の役職確認
- **無法者**（コスト1）：投票後、敗北時に他プレイヤーと役職交換
- **村長**（コスト3）：投票権2票
- **怪盗**（コスト1）：他プレイヤーと役職交換可能
- **スパイ**（コスト2）：人狼陣営と相互確認、投票フェーズで人狼プレイヤーのみ「通報」可能

### 人狼陣営

- **大熊**（コスト5）：処刑された場合、人狼陣営過半数で強制勝利
- **占い人狼**（コスト4）：占い師と同様の能力、人狼同士確認不可
- **やっかいな豚男**（コスト4）：指定したプレイヤーの投票先を強制指定できるが自身は投票権を失う
- **蛇女**（コスト3）：同数投票で処刑時、単独勝利
- **博識な子犬**（コスト3）：場札の市民陣営役職を推測できる、正解で持ち点2点回復

## 開発環境の準備

1. このリポジトリをクローンする
```
git clone https://github.com/Danchi17/wolfgame.git
cd wolfgame
```

2. Firebaseプロジェクトを作成する
   - [Firebaseコンソール](https://console.firebase.google.com/) から新しいプロジェクトを作成
   - Realtime Databaseを有効化
   - Authenticationで匿名認証を有効化

3. `database.rules.json`ファイルをFirebaseに反映させる

4. `firebase.js`のAPIキーを自分のプロジェクトのものに置き換える

## ゲームプレイ方法

1. 4人以上のプレイヤーを集める
2. ホストプレイヤーがゲームを作成し、URLを共有
3. 全員が準備完了したらホストがゲームを開始
4. 夜フェーズで役職に合わせて行動
5. 日中フェーズで議論（外部ボイスチャットを使用）
6. 投票フェーズで処刑するプレイヤーを決定
7. 結果確認フェーズで勝敗を判定し、持ち点を更新
8. 継続して遊ぶか、誰かのプレイヤーの持ち点が0以下になるまで繰り返す
